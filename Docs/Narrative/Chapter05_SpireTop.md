# 第⑤章 · 塔尖 · 「钟声」

| 字段 | 值 |
|---|---|
| 所属幕 | 第二幕 · 月光转折（表层与内层的界面） |
| 主线时长 | 30-45 分钟（含 Boss） |
| 配乐核心 | 李斯特《钟》（La Campanella）改编；坠落段为纯寂静 |
| 入队角色 | 无 |
| Boss | 时钟守卫（主线 Boss，三阶段） |

## 1. 章节定位

这是游戏的**第一个主线 Boss**，也是第一幕到第二幕的情绪顶点，更是**整个游戏最重要的叙事节点之一**——世界是倒悬的揭示、纵身一跃的转折，都发生在本章 Boss 战之后。

它在结构上承担两件事：以一场高强度的节奏型 Boss 战收束"调性 / Tempo"系统的上半程教学；用一个**视觉主导**的叙事揭示完成"认知翻转"，把玩家从表层世界推入内心世界。

## 2. 场景细节

### 2.1 Boss 战场地

塔顶平台。矮墙围成一圈。地面有水——不是漏水，而是**整个塔顶仿佛浮在一层极薄的水面上**。水面倒映着月光。

### 2.2 Boss 战后

月亮从云层后重新出现，但只有朦胧的轮廓，被一层薄雾笼罩。整个塔顶平台沐浴在这种不清不楚的月光中。没有背景音乐，只有风声和极其遥远的水声。

**关键视觉揭示**（通过镜头缓慢下移完成）：主角走到塔边缘向下望——

- 湖面映射的不是塔的倒影。
- 湖面映射的是**真实的星空**——银河、星座、流星。
- 而头顶的天空只有雾和月亮。
- **水面下才是真实的天空。他们一直站在天空的倒影上。世界是倒悬的。**

## 3. 音乐处理

### 3.1 Boss 战音乐

基于**李斯特《钟》（La Campanella）改编**。

**改编方向：**

- 保留标志性的**高频钟声音型**（反复出现的高音装饰音），将它融入战斗音乐的节奏框架。
- Boss 的攻击节奏和音乐的重拍对齐——当《钟》的旋律到达高潮时，Boss 的伤害最高。
- 音乐分层：

| 层 | 内容 |
|---|---|
| 基础层 | 持续的钟声音型 |
| 战斗层 | 弦乐和打击乐的战斗编配 |
| Boss 阶段层 | 随 Boss 血量变化，音乐变得更紧张或更混乱 |

### 3.2 坠落段

Boss 战后到倒置之塔之间，音乐经历：**钟面碎裂的最后一声清脆钟响 → 寂静 → 主角收音机自动播放微弱未知信号 → 纵身一跃 → 纯白 → 翻转**。

详见本章 §5 关键事件。

## 4. 叙事意图

### 4.1 Boss 战

情感目标：

- **失控的节拍**：让玩家在战斗中**体感**到"时间不规律"的不安——这呼应了"世界停在休止符上"的核心设定，但以更暴烈的方式呈现。
- **节奏的武器化**：鼓的 Tempo 控制从教学走向实战核心。

### 4.2 转折

情感目标：

- **认知翻转**：玩家应和主角一起，在看到"水面下是真实星空"的瞬间感到震惊与释然的混合——原来如此。
- **放手**：纵身一跃不是英雄式的决断，而是一种**"停止抗拒、接受引力、让自己落入未知"**的平静。

## 5. 关键事件

1. 玩家从第④章塔顶进入 Boss 战场地——薄水覆盖的塔顶平台。
2. 时钟守卫现身，Boss 战开始。
3. **第一阶段「齿轮转动」**（100%-60% HP）——走走停停的坏钟节奏。
4. **第二阶段「发条过紧」**（60%-30% HP）——狂暴、恒定高速、自我齐奏回盾。
5. **第三阶段「指针断裂」**（30%-0% HP）——调性强制 Dissonant，Boss 转为消除己方音符制造"寂静"。
6. Boss 被击败，钟面彻底碎裂，碎片散落发出**最后一声清脆的钟响**。
7. 然后——**安静**。月亮重现但朦胧，塔顶浸在不清不楚的月光中。
8. 主角的留声机/收音机自动播放——不是之前收集的任何旋律，而是一段**从未听过的、极其微弱的信号**。信号来自**下方**。
9. 镜头缓慢下移，对准塔顶地面薄水——水面倒映的不是月亮，**倒映的是星空**。
10. 主角走到塔的边缘向下望——湖面映射的是真实的星空，头顶天空只有雾和月亮。**世界是倒悬的。**
11. 主角的收音机指示灯剧烈闪烁。可选文本（如收音机频段）：

    ```
    ——信号源……确认。
    ——位于……反面。
    ——需要……穿越。
    ```

12. **纵身一跃**——主角倾身向前，倒向湖面。下坠过程中画面慢慢旋转 180 度。他"落入"湖面的一瞬间没有水花，像穿过一面镜子。
13. 画面在纯白中停留一秒。
14. **翻转**——进入第⑥章倒置之塔。

## 6. 战斗设计 / Boss 设计

### 6.1 Boss 概念

| 项 | 内容 |
|---|---|
| 名称 | 时钟守卫 |
| 形态 | 巨大的钟表机械体。中心是一个古老的钟面（罗马数字），指针已停止。围绕钟面有齿轮、发条、钟摆等元素。它的"身体"由这些零件组成，整体呈人形但不完全——上半身是人形轮廓，下半身完全是齿轮和弹簧。 |
| 叙事身份 | 这座塔的"节拍器"——曾经维持塔内时间（节奏）流动的存在。当世界停在休止符上时，它也被卡住了，但它不像其他存在那样安静地停滞，而是**疯狂地试图让自己重新走动**。它的攻击本质上是"失控的节拍"——忽快忽慢、毫无规律的节奏暴力。 |

### 6.2 三阶段机制

| 阶段 | HP 区间 | 名称 | 行动模式 | 特殊机制 | 玩家策略 |
|---|---|---|---|---|---|
| 一 | 100%-60% | 「齿轮转动」 | **不均匀**——有时极快连续行动两次，有时极慢几乎不动。模拟"走走停停的坏钟"。 | 每次行动给己方全体挂一个随机音符（模拟"滴答声"），这些音符有一定概率自动形成不协和音——若玩家不处理，会受到持续反噬。 | 利用鼓的 Tempo 控制稳定己方行动节奏；抓住 Boss"停顿"的间隙集中输出。 |
| 二 | 60%-30% | 「发条过紧」 | 进入狂暴状态，行动速度极快且恒定。 | Boss 开始给自己挂音符标记——尝试在自己身上形成"齐奏"（同音叠加），每次成功齐奏大幅恢复护盾。 | 利用有改写能力的角色（如已获得双簧管）破坏 Boss 的齐奏企图；或用不协和音主动触发真实伤害绕过护盾。 |
| 三 | 30%-0 | 「指针断裂」 | 钟面裂开，指针脱落变成武器。攻击方式从"节奏失控"变为"直接物理暴力"。 | **场地调性强制变为 Dissonant**——双方不协和音伤害都增加，反噬也增加。Boss 不再挂音符，而是**消除己方身上的音符标记**——它在试图制造"寂静"。 | 与时间赛跑——快速挂音符、快速触发共鸣，在音符被消除前完成和弦。鼓的"重拍"在这一阶段至关重要。 |

### 6.3 转折演出要点

纵身一跃的处理需要极其谨慎：

- **不应该是"勇敢的跳跃"或"英雄式的决断"**。它应更接近于**"放手"**——一种停止抗拒、接受引力、让自己落入未知的平静。

视觉处理建议：

- 主角站在塔边，停顿。
- 没有任何按键提示。如这一幕是过场，那就让它自动发生；如要交互，那只需要玩家做一个简单的动作——比如向下滑动屏幕，或松开一直按住的某个键。
- 主角倾身向前，倒向湖面。
- 下坠过程中，画面慢慢旋转 180 度——上变成下，下变成上。
- 他"落入"湖面的一瞬间，没有水花——就像穿过一面镜子。
- 画面在纯白中停留一秒。

## 7. 教学内容

参考 [CharacterDesign.md §12](../CharacterDesign.md) 的教学曲线。

| 教学项 | 内容 |
|---|---|
| Tempo 控制（鼓核心） | Boss 不均匀行动条 → 鼓的 Tempo 控制从教学走向实战核心 |
| 改写机制实战 | 二阶段 Boss 自挂音符齐奏 → 双簧管改写机制的实战应用 |
| 真实伤害绕盾 | 二阶段不协和音主动触发真实伤害——绕过护盾的进阶策略 |
| Dissonant 风险与机会 | 三阶段强制 Dissonant → 让玩家理解"调性对双方都生效" |
| 寂静对抗 | 三阶段 Boss 消除音符 → 教学快速共鸣与"重拍"价值 |

## 8. 美术与视听要点

### 8.1 Boss 美术

| 元素 | 要求 |
|---|---|
| 钟面 | 古老、罗马数字、指针停止 |
| 齿轮 / 发条 / 钟摆 | 半人半机械，下半身纯零件 |
| 三阶段演变 | 阶段三钟面裂开、指针脱落化为武器——视觉上必须明显 |

### 8.2 转折演出

| 元素 | 要求 |
|---|---|
| 薄水镜面 | 塔顶地面薄水，倒映月光——质感是镜面而非湿地面 |
| 镜头下移 | 缓慢、克制；不切镜，让观众与主角一起发现 |
| 倒置星空 | 湖面映出的星空必须让人一眼分辨出"是星空不是水面倒影"——具体亮度/对比度需调校 |
| 180 度旋转 | 下坠过程中的画面旋转不能眩晕，需保留方位感 |
| 纯白停留 | 1 秒——节奏关键 |

### 8.3 音乐与音效

| 元素 | 要求 |
|---|---|
| La Campanella 改编 | 高频钟声音型必须穿透战斗层，作为 Boss 的"声音签名" |
| 音乐与 Boss 节奏对齐 | 高潮处 = Boss 伤害最高处——需要音频中间件实现节拍同步 |
| 阶段层音乐变化 | 三阶段需有明显的紧张度曲线变化 |
| 钟面碎裂最后一声 | 清脆、干净、单音——是 Boss 战音乐到寂静之间的桥梁 |
| 未知信号 | 收音机自动播放的未知信号需区别于已收集的所有旋律——预告拉赫第二钢琴协奏曲 |
| 坠落寂静 | 纯静默——与序幕"碎裂瞬间"后的白噪音形成对照 |
