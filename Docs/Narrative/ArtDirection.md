# 美术方向与角色视觉概念

## 1. 总体方向

### 1.1 项目定位

Project Sonata 是**单机买断制的独立游戏**，不是持续运营的二次元手游。角色设计目标不是"让人想抽卡"，而是**"让人在体验过程中对这些角色产生情感连接"**。

| 抽卡驱动设计 | 体验驱动设计 |
|---|---|
| 第一眼吸引力极高 | 在游戏情境中有记忆点 |
| 立绘需独立于游戏情境 | 性格 / 声音 / 行为模式比外表更重要 |
| 需要"想拥有"的欲望 | 需要"想了解"的好奇心 |
| 依赖人类面孔、身体比例、服装 | 可高度风格化、非人类、抽象 |

**Project Sonata 走第二条路。**

### 1.2 参考作品

| 作品 | 借鉴维度 |
|---|---|
| 《空洞骑士》 | 非人形角色的情感表达、模糊叙事 |
| 《Wall-E》 | 通过动作 / 声音 / 指示灯传达情绪 |
| 《纪念碑谷》 | 极简视觉承载重量级叙事 |
| 《Undertale》 | 像素角色承载强烈情感 |
| 《Celeste》 | 极简主角承载深刻主题 |
| 《重返未来：1999》 | 欧洲近代美术气质（但不照搬人物设计风格） |

## 2. 三条候选路径

### 路径 A：纯粹的乐器形态

```
角色就是乐器本身。
小提琴 = 一把漂浮的小提琴。
钢琴 = 一架钢琴。
鼓 = 一面鼓。
通过乐器的运动方式、光效、声音来传达情感。
```

**优点**：风格极其统一、与世界观完美契合、独一无二的诗意气质
**难点**：情感传达完全依赖动画 / 光效 / 声音，对话场景表现力受限

**参考**：迪士尼《幻想曲》、《Wall-E》

### 路径 B：人形化的乐器角色（二次元式）

```
角色是带有乐器元素的人形。
小提琴 = 纤细的少女，头发像琴弦。
钢琴 = 黑白分明的角色，手指极长。
```

**优点**：情感传达容易、Live2D 可充分发挥、易吸引主流玩家
**难点**：泯然众人（市场上"乐器主题二次元角色"已饱和）、与项目独特气质冲突

### 路径 C：介于两者之间的"具身化"设计 ⭐ 推荐

```
角色既不是纯粹的乐器，也不是"乐器主题的人类"。
它们是乐器在获得意识之后"试图理解人形"的不完整尝试。
```

**核心理念**：角色有**大致的人形轮廓**（头/躯干/四肢基本可辨认），但身体**明显由乐器部件构成**，且**不追求完美的人体比例**。

## 3. 路径 C 的设计依据

### 3.1 人形可读性

玩家可以从轮廓、姿态、动作中读取情感——大脑有很强的拟人化本能。只要有大致的头/身/肢结构，玩家就会自动把它读成"某种人"。

但因为明显不是人类，所以不会和二次元美少女竞争，而是建立自己的审美语言。

### 3.2 乐器性始终可见

路径 B 中，乐器元素是装饰——脱掉服装设计，角色就是普通人。路径 C 中，**乐器性是身体本身**。

- 小提琴不是"拿着小提琴的少女"，她**就是**小提琴
- 钢琴不是"穿着燕尾服的男人"，他**就是**钢琴
- 强化世界观一致性：这个世界里没有"人"，只有乐器、声音、旋律

### 3.3 独特的审美辨识度

市面上没有这种美术风格的游戏。当玩家在社交媒体上看到一张截图——一个小提琴轮廓的人形站在月光下的尖塔上——他不会把它和任何其他游戏混淆。

### 3.4 与叙事主题深度统一

这些角色是"失落的声部"——它们是乐器获得了意识，但**还不完全理解自己是什么**。它们半人半器的形态本身就是叙事表达：**它们在试图成为"完整的存在"，但还没有做到**。它们的旅程（和主角的旅程一样）是**走向完整**的过程。

## 4. 角色视觉概念

### 4.1 小提琴（Strings）

| 部位 | 设计 |
|---|---|
| 整体轮廓 | 纤长的人形 |
| 头部 | 小提琴的**卷轴（scroll）**——那个螺旋形状本身就有一种优雅的表情感。没有传统意义的"脸" |
| 躯干 | 琴身 |
| "眼睛" | **f 孔**——像两只半闭的眼睛 |
| 手臂 | 一只是琴弓，另一只是可以活动的指板 |
| 腿 | 琴弦延伸变化形成的线条（不完全是人类腿形，更像是站立的弧线） |

**情感表达机制**：
- 卷轴的倾斜角度（低头=沮丧，抬起=警觉）
- f 孔的"眨眼"式开合
- 琴弦的振动频率（紧张时弦绷紧发出高频泛音，放松时弦松弛发出温柔泛音）

### 4.2 长笛（Winds）

| 部位 | 设计 |
|---|---|
| 整体轮廓 | 极其纤细的人形，几乎像一条垂直的银色线 |
| 头部 | 长笛的吹口——永远微微侧脸的姿态（长笛横着吹） |
| 身体 | 管身 |
| 脊椎 | 按键排列 |
| 行走 | 飘逸感，像气流 |

**情感表达机制**：
- 管身的按键开合（像在"呼吸"）
- 吹口处气流的可见化（紧张时气流急促，平静时缓慢）

### 4.3 鼓（Drum Kit）

| 部位 | 设计 |
|---|---|
| 整体轮廓 | 矮壮的人形 |
| 头部 | 小型定音鼓，鼓面可以表现"表情"——张力变化让它像嘴一样开合 |
| 身体 | 各种打击乐器的组合 |
| 胸腔 | 大鼓 |
| 手臂 | 鼓槌作为手掌 |
| 背部 | 背着镲 |
| 行走 | 不是"走"，是带节奏的跳步——每一步都有声音 |

**情感表达机制**：
- 鼓面的震动模拟人脸的微表情
- 鼓点的速度和力度直接反映情绪

### 4.4 钢琴（Polyphonic）

| 部位 | 设计 |
|---|---|
| 整体轮廓 | 最接近人形的角色（钢琴是"乐器之王"，与人的关系最密切） |
| 上半身 | 黑色燕尾服（像三角钢琴外壳），肩宽且有力 |
| 双手 | 完整的十指，手指是黑白相间的琴键 |
| 下半身 | 三条弯曲的钢琴腿（像维多利亚时代的家具腿） |
| 头部 | 琴盖——半开状态 |

**情感表达机制**：
- 说话时是琴弦在振动
- 强烈情绪时琴盖完全打开或猛然合上
- **黑白键双人格**通过琴盖角度表现：盖子开大 = 白键人格（开放、温暖），盖子半合 = 黑键人格（收敛、尖锐）
- 切换人格时的变形动画：琴盖翻开 → 内部弦列暴露 → 击槌运动 → 完全不同的姿态和配色

### 4.8 留声机主角（Protagonist）

| 部位 | 设计 |
|---|---|
| 整体轮廓 | 最不像"人"的角色——但反而最有辨识度 |
| 身体 | 古老的留声机箱体 |
| 一侧 | 手摇柄 |
| 头部 | 留声机的大喇叭口——朝向哪里就是"面向"哪里 |
| 四肢 | 没有明显的四肢——移动方式是地面滑行或短距跳跃；或两条细小的、有点滑稽的小腿 |
| 表情来源 | 指示灯（最重要）——不同颜色、不同闪烁模式代表不同情绪 |

**喇叭口的情感表达**：
- 深且暗 = 沉默 / 沮丧
- 浅且亮 = 好奇 / 快乐
- 微微抬起 = 听到熟悉旋律（关键情感时刻）

**指示灯语言**：
- 红色慢闪 = 待机
- 绿色快闪 = 接收到信号
- 蓝色常亮 = 沉思
- 黄色脉动 = 警觉
- 全部亮起 = 收到完整信号（终局时刻）

## 5. Live2D / Spine 适配

### 5.1 对话场景（半身或全身 Live2D）

以小提琴为例：

| 部位 | Live2D 动效 |
|---|---|
| 卷轴（头部替代物） | 倾斜、转向、微微颤动 |
| f 孔 | "眨眼"式的开合 |
| 琴弦 | 振动，频率对应情绪 |
| 琴弓手臂 | 手势 |
| 整体姿态 | 重心偏移（Live2D 最擅长） |

### 5.2 战斗场景（全身 Live2D 或 Spine）

攻击动画天然映射到乐器演奏动作：

| 乐器 | 攻击动画 |
|---|---|
| 小提琴 | 拉弓 |
| 长笛 | 吹奏 |
| 鼓 | 敲击 |
| 钢琴 | 落指 |

### 5.3 Boss 和关键剧情

高品质 Live2D 或预渲染动画。**因为角色不是标准人形，反而在动画上有更大的自由度**：

- 钢琴角色在切换人格时，整个身体可以做"翻转"动画——琴盖翻开 → 内部弦列暴露 → 击槌运动 → 完全不同的姿态和配色
- 这种变形在标准人形角色上很难做，但在乐器角色上极其自然

## 7. 关键美术策略

**先做主角，完美做主角，只做主角。**

留声机主角是全游戏出镜率最高的角色。如果玩家在前 15 分钟内爱上这个小留声机——爱它的指示灯闪烁方式、爱它笨拙的移动、爱它在找到旋律碎片时喇叭口微微抬起的样子——那玩家就已经接受了这个游戏的美术语言。

后续出现的所有角色都会被自动纳入这个审美框架中。

### 7.1 美术优先级

| 优先级 | 内容 |
|---|---|
| 🔴 最高 | 主角的探索形态（小比例角色，可能只有剪影 + 指示灯） |
| 🔴 最高 | 主角的对话 / 剧情 Live2D（如有） |
| 🟠 高 | 第一个队友（小提琴）的战斗形态和对话形态 |
| 🟡 中 | 其他核心队友（长笛、鼓） |
| 🟡 中 | 第一个 Boss（时钟守卫） |
| 🟢 低 | 支线角色、普通敌人 |

**不要一开始就设计所有角色。先做一个角色到极致，验证美术风格是否成立。**

如果玩家在看到留声机主角的第一眼时反应是"好可爱"或"好有意思"或"我想了解更多"，那美术方向就对了。

## 8. 关于"吸引力"的重新定义

**吸引力不只有性别魅力这一种。**

| 角色 | 表面"非人"特征 | 玩家为什么爱他们 |
|---|---|---|
| Wall-E | 方形垃圾压缩机器人，无嘴无鼻，两个望远镜眼睛 | 动作设计、声音设计、情境关联 |
| Hollow Knight 中的大黄蜂（Hornet） | 完全的虫子，无任何人类特征 | 叙事赋予的情感重量 |
| 《纪念碑谷》中的艾达 | 白色三角锥帽小人，连五官都看不清 | 极简美学与情境诗意的结合 |

Project Sonata 的角色有一个二次元美少女**做不到**的优势：**它们的声音就是它们的灵魂。**

当小提琴角色"说话"时，响起的是小提琴的声音。当她悲伤时，那是小提琴最低沉的音色。当她振作时，那是小提琴最明亮的高音。**玩家对一把小提琴音色的情感反应，远比对一张漂亮脸蛋的反应更加深层和持久。**

让角色的**视觉形态和听觉形态共同构成一个完整的"人格"**——这是 Project Sonata 美术/音频融合可以达到的高度。

## 9. 决策日志

### 2026-07-19 · 采用路径 C（具身化乐器角色）

**决定**：所有角色采用路径 C 设计——大致人形轮廓 + 明显乐器部件构成 + 不追求完美人体比例。

**理由**：
- 兼顾情感可读性与世界观独特性
- 乐器性是身体本身而非装饰
- 市面上无同类美术风格，辨识度极高
- 与"角色是不完整的声部，旅程是走向完整"的叙事主题深度统一

### 2026-07-19 · 主角美术优先级最高

**决定**：留声机主角的探索形态 + 对话形态为全游戏最高优先级美术任务。

**理由**：
- 主角出镜率最高
- 玩家接受主角 = 接受整个美术语言
- 验证美术方向是否成立最直接的试金石
