# 世界观与基本设定

## 1. 核心设定

世界是一首**停滞在"休止符"上的未完成交响曲**。

- **风雪**是信号缺失的"白噪音"
- **极光**是天际飘荡的"磁带"
- 整个世界在等待被重新"播放"

## 2. 世界基调

| 维度 | 表达 |
|---|---|
| 美术气质 | 欧洲中世纪 / 近代、神秘学、古典乐、雪、雾、月光、极光、舞台布景感 |
| 核心情绪 | 优雅、忧郁、浪漫主义、疗愈与补全 |
| 视觉锚点 | 灰白色调起手，随剧情推进逐渐染色（直至终章极光与黎明） |
| 音乐哲学 | 音乐不是装饰，而是叙事本身——每个场景、敌人、战斗都在讲述同一个故事 |

## 3. 主角设定

### 3.1 身份

主角是**留声机/收音机化形**，叙事身份为**"寻频者"（Tuner）**。

- 唯一能**记录并播放**外界信号的存在
- 负责接续断掉的旋律
- 旅程的内在逻辑：从"被动的载体"变为"主动的演奏者"

### 3.2 弧光

主角的旅途不是"接到任务去修复世界"，而是：

```
他不知道自己在找什么。
但每次他找到一段旋律碎片，他的身体会产生共鸣——
一种"这个声音属于我"的物理反应。
他在一路找回自己丢失的声音。
直到最后在废弃车站，他找回完整的旋律——
那就是他曾经播放的音乐。
那就是他自己。
```

这对应拉赫玛尼诺夫的真实经历：他不是"学会了新技能然后写出第二钢琴协奏曲"，而是**找回了自己本来就有的、被创伤埋葬的创作能力**。

### 3.3 选项：主角是否曾经是拉赫的留声机

> 设计倾向：主角是序幕中碎裂的音乐厅里那台留声机。他曾播放过完整的、美丽的音乐，然后一切碎了，他失去了所有录音，只剩下白噪音。他甚至不记得自己曾经播放过什么——序幕中的和弦是他"遗忘的记忆"的最后一道残响。

详见 [Prologue.md](./Prologue.md)。

## 4. 主角名字

### 4.1 候选方案

来自设计笔记的几条思路（基于 Sergei Rachmaninov 反转）：

| 思路 | 推导 | 结果 |
|---|---|---|
| Sergei 反转 | Sergei → Iegres → 简化 | **Igres** 或 **Eires** |
| Rachmaninov 反转 | Rachmaninov → Voninamhcar → 提取音节 | Vonir / Nahcar / Manov |

**当前倾向**：**Igres**（来自 Sergei 反转的 Iegres 简化）。

- 读起来像一个真实的名字
- 不会让玩家觉得是乱码
- 知道典故的人会心一笑

## 5. 游戏类型定位

- **2D 固定视角 / 2.5D 舞台式探索** + **指令式卡牌 / 回合制 RPG**
- **不是传统下落式音游**
- 把古典乐理（和声、调性、节奏）解构为核心战斗逻辑
