# 第①章 · 雪国列车 · 「无信号」

| 字段 | 值 |
|---|---|
| 所属幕 | 第一幕 · 灰色世界（物理表层） |
| 主线时长 | 5-10 分钟 |
| 配乐核心 | 无配乐，仅白噪音；偶发信号碎片 |
| 入队角色 | 无 |
| Boss | 无 |

## 1. 章节定位

本章是序幕之后玩家**第一次真正进入交互**的段落，也是整个游戏情绪曲线的最低点——白噪音、模糊、未知。它承担三件事：让玩家从序幕的"碎裂瞬间"中"醒来"、建立**"失联"**这一核心感受、用最微弱的视觉变化（指示灯闪烁、雾气散开）给出第一个前进的引力。

它与第⑨章「黎明列车」构成**首尾呼应**——同一辆列车、同一扇窗，但窗外的世界在终章将完全不同。这层结构性对称详见 [HiddenThreads.md](./HiddenThreads.md)。

## 2. 场景细节

画面极度简约。不是"省略了内饰"，而是**这个世界本身就尚未被信号填充**。

- **屏幕中央偏左**：一个简笔勾勒的座椅轮廓，主角坐在上面——但主角的形象也是模糊的，只有一个**留声机喇叭口的剪影**，和隐约闪烁的**收音机指示灯**。
- **屏幕右侧**：一个长方形的窗。窗上凝着水雾，雾气缓慢地流动。玩家可以看到雾气背后有**极其模糊的形状在移动**——也许是树，也许是建筑，也许什么都不是。
- **声音**：没有背景音乐。只有白噪音——那种老式收音机在频道之间搜索时发出的沙沙声。偶尔，白噪音里会闪过一个极其微弱的音符碎片，像是在远方有人弹了一个音，但随即被噪音吞没。

## 3. 音乐处理

本章**不使用任何背景音乐**，全部由白噪音构成。

- 白噪音的质感参考老式收音机搜频时的沙沙声，不是均匀的"白噪声"合成。
- 偶发的音符碎片在序幕语境下应被理解为**拉赫玛尼诺夫第二钢琴协奏曲开头和弦的某个组成音**（详见 [Prologue.md §5](./Prologue.md)）——极短极弱，几乎听不到，但在那个音出现的瞬间，主角的收音机指示灯会微微亮一下。
- 这是全游戏"信号"概念的第一次落地：白噪音不是结局，白噪音里面藏着旋律。

## 4. 叙事意图

这一幕建立的是**"失联"的感受**。玩家不知道自己是谁、在哪里、要去哪里。主角作为一台收音机/留声机，此刻什么信号都收不到。世界对他而言就是白噪音。

情感目标：

- **麻木感**：玩家应该感到一种钝的、不锐利的空虚，而不是激烈的悲伤。
- **微弱的牵引**：当列车停下、雾气散开露出外界时，玩家应产生"那里好像有什么"的本能好奇——而不是被任务文字驱使。

## 5. 关键事件

1. 玩家在列车内醒来，画面极度简约，只有白噪音。
2. 玩家可触摸/点击窗户上的雾气——划过的地方雾气暂时散开，露出窗外朦胧、不确定的景色（每次划开看到的内容可随机或半固定：一棵树的轮廓、一段铁轨的弧线、一片雪原）。
3. 玩家可以选择不做任何事——等待会让白噪音持续一段时间。
4. 列车开始减速，窗外模糊形状变得更慢，最终停下。
5. 窗外的雾气自行散开一小块，露出一扇门的轮廓或一段通往外界的小路。
6. 主角的指示灯闪了一下——这是整个游戏**第一个有意义的视觉变化**。
7. 可选文本（出现在画面底部，像收音机频段上的字）：

   ```
   ——检测到……微弱信号。
   ——方位……不明。
   ——自动寻频……启动。
   ```

8. 画面从列车内部过渡到外界，进入第②章。

## 6. 战斗设计 / Boss 设计

无战斗。本章不含任何战斗或教学遭遇，玩家唯一能做的是触摸雾气与等待。

## 7. 教学内容

本章不引入任何战斗或角色机制。它隐性地教学**"这个世界可以互动，并且会回应"**——这是后续一切探索与战斗教学的前置心理契约。

详见 [CharacterDesign.md §12.2](../CharacterDesign.md) 关于教学曲线的总览。

## 8. 美术与视听要点

| 元素 | 要求 |
|---|---|
| 列车内饰 | 极度简笔，留白为主——不要补全细节，缺失感本身是设计 |
| 主角剪影 | 只有留声机喇叭口的轮廓 + 收音机指示灯（可闪烁） |
| 窗与雾气 | 雾气需有流动感；划开后透出的形状必须**朦胧、不确定**，不能清晰 |
| 白噪音 | 老式收音机搜频质感，非均匀白噪声 |
| 信号碎片 | 偶发的极弱单音，配合指示灯闪烁 |
| 频段文字 | 字体需像老式收音机刻度盘，底部出现 |
