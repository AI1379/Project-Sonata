# 总体叙事结构

## 1. 三幕式深层结构

九段式章节天然对应一个完整的"心理治愈弧光"，按三幕组织内在逻辑：

```
第一幕：灰色世界（物理表层）
  ① 雪国列车 → ② 雾中花园 → ③ 黑森林
  关键词：麻木、失忆、被动前行
  音乐色彩：沉默 → 肖邦式忧伤 → 中古调式的原始恐惧

第二幕：月光转折（表层与内层的界面）
  ④ 湖中尖塔 → ⑤ 塔尖Boss战 → 纵身一跃
  关键词：幻美、试炼、认知翻转
  音乐色彩：月光奏鸣曲第一乐章 → 李斯特《钟》→ 坠落时的寂静

第三幕：倒悬深渊（内心世界）
  ⑥ 倒置之塔 → ⑦ 来时路的重放 → ⑧ 废弃车站Boss战 → ⑨ 黎明列车
  关键词：直面、撕裂、和解、重生
  音乐色彩：月光第三乐章 → 无调性 → 拉赫玛尼诺夫第二钢琴协奏曲
```

## 2. 深层隐喻

**主角本身就是拉赫玛尼诺夫（或任何一个经历过创作危机与抑郁的艺术灵魂）的投射。**

留声机/收音机的化形——他不创造音乐，只能记录和播放别人的旋律，而整个旅程是他**从"被动的载体"变成"主动的演奏者"**的过程。

详见 [HiddenThreads.md](./HiddenThreads.md)。

## 7. 关键叙事节点

下列节点是**整个游戏不可省略的核心时刻**：

1. **序幕**：拉二和弦响起 → 失真 → 白噪音（建立情感契约）
2. **花园共鸣**：第一次触发和声共鸣，画面瞬间鲜艳（玩家第一次"做到"）
3. **塔尖揭示**：水面映出星空，世界是倒悬的（认知翻转）
4. **纵身一跃**：主角主动从塔边坠落（接受、放手）
5. **倒置遇敌**：发现敌人是失调乐器，对应自身缺陷（自我对峙）
6. **旧录音室**：主角找回记忆碎片，暗示其真实身份（自我揭示）
7. **终局三阶段**：寂静 → 噪音 → 协奏（与抑郁的完整对峙）
8. **极光亮起**：乌云散去，世界修复（释然）
9. **尾声启程**：主角坐回钢琴前，从记录者变为演奏者（弧光完成）
