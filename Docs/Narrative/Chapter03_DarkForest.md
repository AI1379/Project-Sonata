# 第③章 · 黑森林 · 「低频」

| 字段 | 值 |
|---|---|
| 所属幕 | 第一幕 · 灰色世界（物理表层） |
| 主线时长 | 40-60 分钟（含支线：大提琴、双簧管） |
| 配乐核心 | 原创作曲，中古调式（多利亚 / 弗里吉亚），低音弦乐 + 管风琴 + 偶尔木管 |
| 入队角色 | 大提琴（支线）、双簧管（支线） |
| Boss | 无主线 Boss；含两场支线教学战 |

## 1. 章节定位

黑森林是**花园的反面**：花园忧伤但安全，黑森林开始危险了。它在叙事上承担两件事：建立**恐惧**和引入**"失调"**的概念。在系统层面，它是防御机制（大提琴）与改写机制（双簧管）的教学区。

这是第一幕的最后一章，也是"灰色世界"基调最沉重的一段。它的结尾——"穿过森林最密处，眼前豁然开朗"——为第二幕月光幻美的湖中尖塔做出情绪反差。

## 2. 场景细节

离开花园后，路变窄，光变暗。这是一片**被重低音控制的森林**。不是普通的中世纪黑暗森林——这里的黑暗是**声学性质的**：

| 元素 | 描述 |
|---|---|
| 树木形态 | 树干极其粗壮，表面有类似乐器共鸣箱的纹理——**年轮像唱片的沟槽**，**树皮上有类似提琴 f 孔的裂缝**。树冠层几乎完全遮蔽天光，只有极少数缝隙中漏下惨白的光线。 |
| 地面 | 黑色的落叶覆盖一切，踩上去不是沙沙声，而是**低沉的嗡鸣，像大提琴的空弦**。 |
| 空气感 | 雾仍然存在，但这里更浓、更低，贴着地面流动，**像低频声波的视觉化**。 |
| 路径 | 不是清晰的道路，而是**树根形成的线条**，像五线谱一样交错分叉。玩家需要选择路径前进。 |

## 3. 音乐处理

本章配乐为**原创作曲**，风格方向：

- **中古调式（多利亚调式或弗里吉亚调式）**——天然带有一种"古老的不安"，既不像大调那么明亮，也不像自然小调那么悲伤，而是有一种**原始的、仪式性的紧张感**。
- 主要乐器：低音弦乐（大提琴、低音提琴）、管风琴低音区域、偶尔的木管（巴松管或英国管）。

**音乐互动设计：** 玩家走不同的路径时，背景音乐的低音线会发生变化——向左走，低音走向下行；向右走，低音走向上行。这不需要让玩家意识到，但潜意识里会影响对路径的选择。

**氛围递进**：森林后半段应从"阴森"变为"压抑"——树木越来越密，路越来越窄；低频嗡鸣越来越强，甚至会让画面产生**轻微的震动效果**；偶尔远处会传来一个非常清亮的、高频的音——像钟声，或像钢琴最高音区的单音——那是湖中尖塔的方向。当玩家穿过森林最密处，眼前豁然开朗。

## 4. 叙事意图

情感目标：

- **声学性恐惧**：不是 jump scare 式的恐怖，而是一种**被低频压迫的生理性不安**。
- **"失调"概念的建立**：玩家首次面对会主动制造不协和音、能反弹音符的敌人，理解"和弦不只属于玩家"。
- **被忽略的声部**：大提琴支线的核心情绪是"我以为自己不重要"——这是抑郁与自我否定最早的回声。

## 5. 关键事件

1. 离开花园，进入黑森林。光变暗，路变窄，雾变低、变浓。
2. 第一次遭遇**空弦兽**——主动给自己挂音符、能自伤全场的新敌人。
3. 路径分叉，玩家选择前进方向（低音线下行 / 上行暗中影响选择）。
4. 遭遇**回声猎手**——会复制玩家上一次使用的音符标记并反弹。
5. 听到极其低沉的、持续的单音（像大提琴 C 弦空弦），循声找到**大提琴角色**——被树根缠绕、被空弦兽包围。
6. **大提琴支线**：完成防御机制教学，大提琴入队。
7. 另一条岔路通向更深的雾区——声音方位被扭曲。
8. 在雾的深处找到**双簧管角色**——一个"信使"，但她传递的信息总是被雾扭曲。
9. **双簧管支线**：完成改写机制教学，双簧管入队。
10. 穿过森林最密处，眼前豁然开朗，进入第④章湖中尖塔。

## 6. 战斗设计 / Boss 设计

无主线 Boss。本章引入两类新敌人和两场支线教学战。

### 6.1 新敌人

| 敌人 | 形态 | 机制 |
|---|---|---|
| 空弦兽 | 一团纠缠的琴弦，没有固定形状 | 发出不协和的低频震动；**主动给自己挂音符标记**，若玩家不及时打断或利用，它们会自己触发不协和共鸣来伤害全场（包括自己，但它们有更高的不协和耐受） |
| 回声猎手 | 一只耳朵和嘴巴融合的怪物 | **复制玩家上一次使用的音符标记**并反弹回来——迫使玩家开始思考音符选择的后果 |

### 6.2 大提琴支线 · 教学战

| 项 | 内容 |
|---|---|
| 入口 | 黑森林深处，循持续低音找到被树根缠绕的大提琴角色 |
| 周围环境 | 大提琴被困在"持续低音"循环中——她只能发出一个音，无法停止、无法改变。这个持续低音的震动吸引了附近所有空弦兽，所以她周围被怪物包围。 |
| 大提琴技能方向 | **防御和持续效果**——持续低音作为护盾（稳定的声波屏障）；低速意味着行动频率低，但每次行动的影响持久 |
| 支线叙事 | 大提琴"失声"的原因是她只记得旋律的最低声部——那个支撑一切但从不被人注意到的声部。她以为自己不重要，所以把自己困在了单音循环里。主角帮她"播放"其他声部的片段，让她意识到**低音是和声的根基**。 |

### 6.3 双簧管支线 · 教学战

| 项 | 内容 |
|---|---|
| 入口 | 黑森林另一条岔路，通往更深的雾区——那里的雾会扭曲声音，玩家听到的方位和实际位置不一致 |
| 双簧管能力 | **改写敌人身上的音符标记**——极强的控制技能 |
| 支线核心矛盾 | 双簧管被困在雾里，因为她自己都无法分辨自己发出的音是否正确 |
| 战斗设计 | 敌人会有"错误的音符标记"，玩家需要用双簧管的能力将它们改写为正确的音，才能触发有效共鸣 |

## 7. 教学内容

参考 [CharacterDesign.md §12](../CharacterDesign.md) 的教学曲线。

| 教学项 | 内容 |
|---|---|
| 防御机制 | 大提琴——持续低音护盾、低速高持续效果 |
| 改写机制 | 双簧管——改写敌方音符标记，从"错误的音"转为"正确的音" |
| 不协和耐受 | 通过空弦兽让玩家理解"敌人也能利用不协和音"，进而理解共鸣不是己方专属 |
| 音符后果预判 | 通过回声猎手让玩家开始思考"我挂的音会不会被反弹" |

## 8. 美术与视听要点

### 8.1 场景美术

| 元素 | 要求 |
|---|---|
| 树干纹理 | 必须保留两个核心意象——**年轮像唱片沟槽**、**树皮上有提琴 f 孔的裂缝**。这是全章视觉的签名 |
| 落叶地面 | 黑色覆盖一切，踩踏反馈是低沉嗡鸣而非沙沙声 |
| 雾 | 比花园更浓、更低，贴地流动，"低频声波视觉化" |
| 路径 | 树根交错如五线谱，分叉明确以承载路径选择 |
| 光线 | 树冠遮天，偶有惨白缝隙光；后半段越来越密 |

### 8.2 音乐与音效

| 元素 | 要求 |
|---|---|
| 原创配乐 | 多利亚 / 弗里吉亚调式，低音弦乐 + 管风琴低音区 + 偶尔木管 |
| 路径低音线 | 玩家左/右走时低音线下行 / 上行——需通过音频中间件实现横向分支 |
| 后半段嗡鸣 | 强度递增，必要时驱动屏幕轻微震动 |
| 远处高频音 | 偶发清亮高频（钟声 / 钢琴最高音），指向湖中尖塔方位——视觉与听觉引导合一 |

### 8.3 大提琴支线环境

- 被树根缠绕的角色形态。
- 周围一圈空弦兽的低频震动效果，使屏幕脉动。
- 持续低音的单音需让玩家在听觉上感到"压迫但又想靠近"。

### 8.4 双簧管支线环境

- 雾的扭曲效果：声音来源方位与画面方位错位。
- 视觉上需要表现"雾在扭曲声音"——也许通过音波纹的可视化被雾打散。
