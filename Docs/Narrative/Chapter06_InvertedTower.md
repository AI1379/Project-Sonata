# 第⑥章 · 倒置之塔 · 「镜像下行」

| 字段 | 值 |
|---|---|
| 所属幕 | 第三幕 · 倒悬深渊（内心世界） |
| 主线时长 | 30-45 分钟（含主角强化支线） |
| 配乐核心 | 贝多芬月光奏鸣曲第三乐章（改编：扭曲、不协和、模糊暴烈） |
| 入队角色 | 无新角色；主角获得"复播"能力（支线） |
| Boss | 无主线 Boss |

## 1. 章节定位

倒置之塔是第三幕的开篇，也是玩家进入**内心世界**后的第一章。它在叙事上承担三件事：完成"表层 → 内心"的视觉与情绪过渡、引入**"失调乐器"**这一敌人性质的根本转换、通过旧录音室支线揭示主角的真实身份暗示。

它的核心设计意图是让玩家**直接感受到——敌人不再是外在的噪音，而是角色们自身缺陷的投影**。

## 2. 场景细节

白色消散后，玩家看到的是**同一座塔——但一切都倒过来了**。

| 元素 | 描述 |
|---|---|
| 重力 | 反转。原来的天花板变成了地面，原来的地面变成了天花板。 |
| 窗外 | 不再是月亮和湖面——窗外是**星空**。真实的、深邃的、无云的星空。 |
| 色调 | 第一幕的灰白调在倒置世界中变为**深蓝和暗紫**。不再是"灰色的压抑"，而是**"深夜的清醒"**——那种凌晨三点失眠时盯着天花板的色调。 |
| 塔内装饰 | 原本的窗户、平台、通道都在，但装饰显著改变。原本的灰石材表面出现了**裂纹**，裂纹中有**微光在流动**——像血管中的光，或像乐谱纸上被擦掉又重写的痕迹。某些原本关闭的门打开了，某些原本开放的通道被封锁了。 |

**方位处理建议：** 让玩家的直觉方位和实际方位产生一种**持续的轻微错位**。比如"下楼梯"在视觉上看起来像"上楼梯"，但主角确实在从塔顶向下（向着塔的底层/水面上的世界的方向）移动。这种错位本身就是**"内心世界不遵循物理规则"**的表达。

## 3. 音乐处理

从塔尖坠落到倒置之塔的过渡中，音乐经历了一个**断裂和重建**：

- **坠落中**：纯粹的寂静。
- **着陆后（翻转完成）**：贝多芬月光奏鸣曲**第三乐章**的改编版突然涌入。

**改编方向：**

- 第三乐章原本就是急速的、激烈的、充满不安的。保留它的核心能量，但让编配更**"扭曲"**——用更多不协和的和声、更尖锐的音色（加入一些电子合成器的质感？或只是把弦乐的混响拉得很长，让它变得更"模糊且暴烈"）。
- **音量不要一开始就拉满**——从远处逐渐逼近，像有什么东西在追赶。

## 4. 叙事意图

情感目标：

- **深夜清醒**：不同于第一幕的灰白麻木，这里是**清醒中的恐惧**——你看得清清楚楚，但你无能为力。
- **自我对峙**：玩家应隐约感受到——这些敌人长得像我们自己用的乐器，它们不是外来怪物。
- **身份揭示**：旧录音室中的记忆碎片让玩家第一次怀疑：主角也许不是凭空出现的留声机。

## 5. 关键事件

1. 画面从纯白消散，玩家看到倒置的塔，重力反转。
2. 月光第三乐章改编版从远处涌入，逐渐逼近。
3. **第一次遭遇失调乐器**——敌人形态从精灵变为漂浮的、破碎的乐器。
4. 在塔内向下（在倒悬世界中即"向外"）探索，路径与第④章塔内位置对应但已变形。
5. 遭遇各种失调乐器——走音的小提琴、破碎的长笛、沉默的鼓、失控的钟。
6. 进入**旧录音室**——它在正常世界的塔中是空房间，在倒置世界里堆满老旧磁带、唱片、录音设备。
7. **主角强化支线**：播放记忆碎片、获得"复播"能力。
8. 离开倒置之塔，进入第⑦章「来时路的重放」。

## 6. 战斗设计 / Boss 设计

无主线 Boss。本章核心是**敌人性质转换**——妖精消失，所有敌人变成"失调的乐器"。

### 6.1 敌人性质转换（关键设计）

| 第一幕（表层世界） | 第三幕（内心世界） |
|---|---|
| 敌人是"外在的噪音"——妖精、精灵、回声 | 敌人是**"内在的失调"**——不是外来怪物，而是主角（或这个世界的原主人）**自己的声音**出了问题 |

### 6.2 失调乐器

| 敌人 | 形态 | 机制 |
|---|---|---|
| 走音的小提琴 | 一把漂浮的小提琴，但琴弦的粗细不对，音柱倾斜，弓毛散开 | 演奏"错误的旋律"——给目标挂的音符标记会比正确的偏高或偏低半音（若系统支持半音则是概念上的"走音"；若只有自然音，则挂的音符在结算时有一定概率变成相邻音） |
| 破碎的长笛 | 一支折断的长笛，断面处有锋利的金属光泽 | 只能吹出**碎裂的、不完整的音符**——挂的音符标记持续时间极短，若不立即被利用就会消失。但攻击频率很高。 |
| 沉默的鼓 | 一面鼓皮塌陷的大鼓 | 不发出声音——但每次"沉默的敲击"会**清除目标身上的所有音符标记**。极其具有威胁性，直接破坏玩家苦心铺设的和弦。 |
| 失控的钟 | 钟表守卫的残骸碎片重组而成的小型钟表怪物 | 随机加速或减速场上所有单位的 Tempo（仅当玩家回到曾经的 Boss 战场景附近时遭遇） |

### 6.3 叙事对应（不必明说）

倒置之塔的敌人是**角色们自身缺陷的投影**：

| 敌人 | 对应角色 | 缺陷 |
|---|---|---|
| 走音的小提琴 | 小提琴角色 | "不够精准" |
| 破碎的长笛 | 长笛角色 | "无法持续" |
| 沉默的鼓 | 鼓角色 | "害怕被听到" |
| 失控的钟 | 时钟守卫（已击败） | 旧伤的残留 |

这些对应关系**不需要直接说出来**，但可以通过角色在遭遇这些敌人时的**反应**来暗示——比如小提琴角色在遇到走音小提琴时，行动会有一瞬间的犹豫（视觉上的微妙表现），或鼓角色在遇到沉默的鼓时，Tempo 增长会暂时降低。

### 6.4 主角强化支线 · 旧录音室

| 项 | 内容 |
|---|---|
| 入口 | 倒置之塔中的旧录音室——在正常世界的塔中是空房间，在倒置世界中堆满老旧磁带、唱片、录音设备 |
| 内容 | 主角找到"自己的旧录音"——但不是声音，而是**记忆碎片**。播放这些碎片会展现一些模糊的画面：也许是一个人在钢琴前，也许是一场暴风雪，也许是一封信的碎片。 |
| 机制奖励 | 完成支线后，主角获得**"复播"能力**——可以记录上一次成功触发的共鸣，在之后的某个时刻重新释放。极强的战术技能，但每场战斗只能使用有限次数。 |
| 叙事揭示 | 这些旧录音暗示了主角的"前世"——他也许不是凭空出现的留声机，而是**某个人的意识/记忆被封装进了这个留声机形态**。这个人可能就是拉赫玛尼诺夫（或拉赫的投影）。详见 [HiddenThreads.md](./HiddenThreads.md)。 |

## 7. 教学内容

参考 [CharacterDesign.md §12](../CharacterDesign.md) 的教学曲线。

| 教学项 | 内容 |
|---|---|
| 复播（主角独占） | 记录上一次成功共鸣并重新释放——每场战斗有限次数 |
| 走音应对 | 走音小提琴让玩家意识到音符结算的不确定性 |
| 时限音符利用 | 破碎长笛的短持续音符 → 教学快速共鸣 |
| 标记保护 | 沉默的鼓清除标记 → 教学节奏管理与"在标记消失前触发" |
| Tempo 波动应对 | 失控的钟随机改 Tempo → 教学应对环境 Tempo 异常 |

## 8. 美术与视听要点

### 8.1 场景美术

| 元素 | 要求 |
|---|---|
| 倒置塔结构 | 与第④章塔位置对应但变形——重力反转、装饰显著改变 |
| 色调 | 深蓝与暗紫——"深夜的清醒"，区别于第一幕灰白 |
| 石材裂纹 | 裂纹中有**微光流动**——像血管中的光或乐谱纸上擦掉重写的痕迹 |
| 窗外星空 | 真实、深邃、无云——区别于第④章的月亮 |
| 通道变化 | 部分原关闭门打开、部分原开放通道封锁——形成新的探索路径 |

### 8.2 方位错位

- "下楼梯"视觉上像"上楼梯"——这种持续的轻微错位本身是叙事表达。
- 需要通过镜头与角色动画精心设计，避免玩家真正迷失。

### 8.3 失调乐器美术

| 敌人 | 美术要点 |
|---|---|
| 走音的小提琴 | 弦粗细不对、音柱倾斜、弓毛散开——所有细节都要"不对" |
| 破碎的长笛 | 断面锋利金属光泽——保留美感与威胁的并存 |
| 沉默的鼓 | 鼓皮塌陷——造型本身即"无言" |
| 失控的钟 | 钟表守卫残骸重组——要与第⑤章 Boss 在视觉上有关联但更破碎 |

### 8.4 旧录音室

| 元素 | 要求 |
|---|---|
| 老旧磁带 / 唱片 | 堆积如山，质感需要照片级真实感 |
| 记忆碎片画面 | 模糊、断续——钢琴前的人、暴风雪、信件碎片 |
| 复播技能视听 | 需有独特的"倒带 / 重放"视觉签名，与普通共鸣区分 |

### 8.5 音乐

- 月光第三乐章改编：扭曲、不协和、模糊暴烈。
- 从远处逐渐逼近的混响处理——音量爬升曲线需调校。
- 是否加入电子合成器质感待定（见 TODO）。
