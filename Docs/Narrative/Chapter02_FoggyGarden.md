# 第②章 · 雾中花园 · 「调谐」

| 字段 | 值 |
|---|---|
| 所属幕 | 第一幕 · 灰色世界（物理表层） |
| 主线时长 | 20-30 分钟 |
| 配乐核心 | 肖邦降 E 大调夜曲 Op.9 No.2（改编：独奏大提琴 / 调性钢琴，节奏放慢，加回声衰减） |
| 入队角色 | 小提琴、长笛、鼓（主线全员入队） |
| Boss | 无 |

## 1. 章节定位

花园是**整个游戏的第一个教学区**，承担三件事：让玩家感受这个世界的"触感"、完成"挂音 → 补音 → 触发共鸣"的核心战斗循环教学、让初始三人组（小提琴、长笛、鼓）依次入队。

它也是音乐从"无"到"有"的第一次显形——肖邦夜曲将在玩家探索过程中被**调谐**出来。这一刻的情绪不同于序幕的庄严悲伤，而是更轻盈、更忧伤的"原来还有这种声音存在"。

## 2. 场景细节

主角走出列车，进入一个**维多利亚式花园**。

视觉层次：

| 层次 | 内容 |
|---|---|
| 前景 | 铁艺花门的弧线，上面缠着已经灰白的藤蔓。门半开着。 |
| 中景 | 碎石小路蜿蜒向前，两侧有低矮的花圃——但花的颜色是**灰蓝的、褪色的**，像老照片。小路中央有一个圆形的小喷泉，水在极其缓慢地流动，发出微弱的水声。 |
| 远景 | 雾气深处有一栋小屋的轮廓，窗口有极其微弱的暖光。再远处是模糊的树影。 |
| 天空 | 没有天空。或者说，天空被均匀的灰白色覆盖，**像一张没有写过任何东西的乐谱纸**。 |

## 3. 音乐处理

这里开始出现背景音乐，但不是直接播放完整的肖邦夜曲。音乐的引入方式和主角设定绑定——**主角是留声机/收音机，他在"调谐"**：

1. 刚进入花园时，仍然有白噪音底色，但明显弱了。
2. 当玩家走近喷泉时，水声和白噪音之间开始出现一个若有若无的旋律——也许是肖邦降 E 大调夜曲（Op.9 No.2）的前几个音，但像是从很远的地方传来，带着失真和断续。
3. 随着玩家在花园中探索，找到一些"音乐碎片"（可以是发光的音符、可以是花瓣、可以是水滴），旋律逐渐清晰。
4. 当玩家完成花园的基础探索后，夜曲以一个**经过改编的、略带忧郁但完整的版本**作为背景循环播放。

**改编方向：** 保留原曲的旋律线，但用更少的乐器（也许只有一把独奏大提琴或一架音色略微失调的钢琴），节奏稍微放慢，在每个乐句结尾加入一点点回声/混响衰减，暗示这个旋律是"从某个遥远的地方被接收到的"。

## 4. 叙事意图

花园的情绪基调是**忧伤但安全**。它是玩家在白噪音之后第一次接触"还有美的东西存在"的世界。

情感目标：

- **温柔的忧伤**：不是绝望，而是一种"这曾经是个美丽的地方"的怅然。
- **第一次"做到"的喜悦**：当共鸣第一次触发、画面瞬间鲜艳时，玩家应该感受到"我让一件美好的事情发生了"。
- **共同体的雏形**：长笛与鼓的加入不应该像 NPC 招募，而应该像**迷失的声部彼此听见**。

## 5. 关键事件

1. 主角从列车下来，穿过铁艺花门进入花园。
2. 走近喷泉，肖邦夜曲的前几个音在白噪音中浮现。
3. 探索花园，拾取"音乐碎片"，旋律逐渐清晰。
4. **第一次遭遇——音乐小妖精**：靠近小屋时，花圃飞出几只拟音化的小妖精（如"颤音精灵"，形态像翅膀上带有音符的蛾子，拍打翅膀时发出高频颤音）。
5. **第一场战斗——单音符教学**（仅小提琴）：理解"技能会给敌人挂上音符标记"。
6. 进入小屋（**第一个存档点/休息点/信息节点**）。
7. **长笛加入**：小屋内部或旁边小场景遇到长笛角色。她是"失声"的存在——能发出音，但单独无法形成旋律。
8. **第二场战斗——双音符与和弦预备**（小提琴 + 长笛）：理解"三度音程"与不协和音反馈。
9. 离开小屋，前往花园出口。
10. **鼓加入**：在花园出口前/中遭遇稍强的节奏型精灵。
11. **第三场战斗——第一次共鸣**（小提琴 + 长笛 + 鼓）：完成"挂音 - 补音 - 触发共鸣"的完整循环。共鸣触发瞬间画面短暂闪光，背景夜曲旋律和战斗音效产生一次"和声"，花园的颜色在那一瞬间变得稍微鲜艳一点。
12. 离开花园，进入第③章黑森林。

## 6. 战斗设计 / Boss 设计

无主线 Boss。本章包含三场教学战。

### 6.1 第一场战斗 · 单音符教学

| 项 | 内容 |
|---|---|
| 地点 | 小屋附近，花圃 |
| 我方 | 小提琴（仅一人） |
| 敌人 | 音乐小妖精（颤音精灵等拟音化小敌） |
| UI | 简化到极致，只有行动条和角色技能 |
| 教学目标 | 让玩家看到"技能会给敌人挂上音符标记"——敌人身上会出现 "C"、"E" 等标记 |
| 强度 | 敌人很弱，几次普通攻击即可消灭 |
| 注意 | **此时不需要触发共鸣**，只需让玩家看到音符标记的存在 |

### 6.2 第二场战斗 · 双音符与和弦预备

| 项 | 内容 |
|---|---|
| 地点 | 小屋内/旁的小场景之后 |
| 我方 | 小提琴 + 长笛 |
| 教学目标 | 让玩家看到两个音符同时挂在敌人身上 |
| 关键反馈 | 小提琴挂 C、长笛挂 E → 系统提示这是"三度音程"，但还不构成完整和弦 |
| 错误反馈 | 若长笛挂 D 形成 C-D → 自动触发不协和音，给玩家直观的"错误反馈" |

### 6.3 第三场战斗 · 第一次共鸣

| 项 | 内容 |
|---|---|
| 地点 | 花园出口 |
| 我方 | 小提琴 + 长笛 + 鼓（三人组齐全） |
| 敌人 | 一只更大的节奏型精灵，攻击模式和节拍有关 |
| 教学目标 | 完成完整的"挂音 - 补音 - 触发共鸣"循环 |
| 视听高潮 | 共鸣触发时画面短暂闪光，背景夜曲旋律与战斗音效产生一次"和声"，花园颜色瞬间变得稍微鲜艳 |

## 7. 教学内容

本章是游戏**最核心的战斗教学区**，按 [CharacterDesign.md §12](../CharacterDesign.md) 的教学曲线展开：

| 教学序列 | 内容 |
|---|---|
| 1. 移动与探索 | 花园本身就是探索场景，无战斗压力，让玩家感受世界的触感 |
| 2. 单音符概念 | 第一场战斗——技能会给敌人挂音符标记 |
| 3. 双音符与音程 | 第二场战斗——三度音程 vs 不协和音 |
| 4. 完整共鸣循环 | 第三场战斗——挂音、补音、共鸣触发 |
| 5. 存档/休息 | 小屋作为第一个存档点与信息节点 |

## 8. 美术与视听要点

### 8.1 场景美术

| 元素 | 要求 |
|---|---|
| 花门 | 铁艺弧线，灰白藤蔓，半开 |
| 花圃 | 灰蓝、褪色，像老照片 |
| 喷泉 | 水流动极慢，微弱水声 |
| 小屋 | 远景中窗口微弱暖光——这是灰色世界里**第一个暖色调光源** |
| 天空 | 均匀灰白，"未写过的乐谱纸"质感 |

### 8.2 小屋内部

- 一张桌子上放着几张**泛黄的乐谱残页**——世界观碎片信息载体。
- 一个壁炉，火很微弱，但存在——暖色调光源。
- 墙上有一面**镜子**——主角在镜中的倒影也许和正面看到的不太一样（为后续"倒悬世界"做伏笔）。

### 8.3 音乐

- 肖邦 Op.9 No.2 改编版，独奏大提琴或失调钢琴，节奏放慢，乐句尾加回声衰减。
- 调谐过程的渐进式清晰化需通过音频中间件实现（Wwise/FMOD 等，具体待定）。

### 8.4 共鸣瞬间

- 第一次完整共鸣触发时的视听反馈是全游戏的情感锚点之一，必须做精：画面闪光 + 颜色饱和度瞬间提升 + 战斗音效与背景旋律形成和声。
