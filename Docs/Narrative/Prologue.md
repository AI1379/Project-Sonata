# 序幕设计（Prologue）

> 在第①章「雪国列车」之前的非交互式过场，长度约 15 秒。

## 1. 设计目标

建立**情感契约**——玩家在游戏前 30 秒内必须达成的契约：

> "有一段极其美丽的音乐曾经存在。它碎了。如果你继续走下去，你也许能让它再次响起。"

不需要找血亲、不需要接委托、不需要打败魔王。**让音乐再次响起**——对于一个有审美感知的玩家来说，这本身就是最强的动机。

## 2. 核心矛盾

游戏主题本身包含一个矛盾：**抑郁症最核心的症状就是"失去动机"**。

主角是一台只有静电噪音的留声机，世界停在休止符上——所有东西都缺乏继续下去的理由。这恰好是要表达的主题。但**如果把这种"缺乏理由"原封不动地传递给玩家，玩家就真的没有理由继续了**。

所以需要找到**一个在沉寂中仍然存在的微弱引力**——就像拉赫玛尼诺夫在最低谷时去找尼古拉·达尔医生接受催眠治疗。他已经几乎不相信自己还能写音乐了，但他还是去了。驱动他的不是"我要写出第二钢琴协奏曲"这样的目标，而是一种更模糊、更本能的东西：**一段旋律的残影，一种"曾经有什么在这里"的感觉**。

## 3. 序幕剧本（约 15 秒）

```
黑屏。完全的寂静。

然后——

一个音响起。
拉赫玛尼诺夫第二钢琴协奏曲开头的那个低音和弦。
浑厚、温暖、庄严。

伴随这个和弦，画面闪现：
一个音乐厅的剪影。模糊的、像隔着磨砂玻璃看到的。
舞台上有一架三角钢琴的轮廓。
有人坐在琴前。看不清脸。
观众席上有无数黑色的身影。

和弦继续共鸣——
第二个和弦叠入。音乐开始展开。

然后——

失真。
就像唱片被划过一样的刺耳噪音。
画面碎裂、扭曲。
音乐被撕成碎片，变成白噪音。
音乐厅的画面被白色吞没。

白色渐渐变成窗上的雾气。

你已经在列车上了。
```

## 4. 序幕做了三件事

1. **让玩家听到"完整的音乐"是什么感觉**
   拉二开头的和弦足以在 15 秒内击中任何人——它不需要你懂古典乐，那个和弦本身就包含了一种庄严的悲伤和力量。玩家在接下来的整个游戏中都会（意识到或潜意识地）追寻"那个声音"。

2. **建立"失去"**
   音乐从完整变成碎裂变成白噪音——玩家亲耳听到了"美好的东西被摧毁"。这是最原始的情感钩子：你知道有什么珍贵的东西碎了，你想把它拼回来。不需要用文字解释。

3. **建立悬念**
   那个坐在钢琴前的人是谁？那个音乐厅是什么？为什么音乐中断了？这些问题不需要立刻回答——它们会像一根细线一样牵着玩家往前走。

## 5. 与第①章「雪国列车」的衔接

有了序幕之后，列车场景的意义变了：玩家不再是"完全不知道在哪里"，而是"刚从那个碎裂的瞬间中醒来"。

列车上加入一个极其微弱的变化：

```
白噪音中，偶尔闪过一个音。
不是随机的音——是序幕中那个和弦的某个组成音。
极短极弱，几乎听不到。
但它在那里。

主角的收音机指示灯在那个音出现时会微微亮一下。
```

这就是**信号**。玩家不需要被告知"去找信号"，他会自己意识到：这个世界里有什么东西在呼唤我。白噪音不是结局，白噪音里面藏着旋律。

## 6. 下车动机

列车停下后，窗雾散开露出外面的世界——但更重要的是，**信号在那个方向更强**。

```
收音机的指针微微偏转。
指向车门外的方向。

可选文本（频段显示）：
——……信号……方位……
——……有什么……在那里……
```

玩家下车的动机不是"我接到了一个任务"，而是**"那里有声音，而我周围只有沉默"**。对于一台留声机来说，走向声音就像对于一个溺水的人来说游向水面——你不需要问他为什么。

## 7. 美术与音效要求

| 元素 | 要求 |
|---|---|
| 音乐厅画面 | 模糊、磨砂玻璃质感、剪影为主，不要让玩家看清钢琴前的人 |
| 拉二和弦 | 必须使用足够浑厚、有重量的录音或合成——这是全游戏的情感锚点 |
| 失真过渡 | 不应该是便宜的电子失真，而应该像"唱片被划过"或"磁带被吞"——有物理质感 |
| 白噪音 | 老式收音机搜频时的沙沙声，不是均匀的"白噪声" |

## 8. 主角身份的暗藏设定

序幕暗示了一个核心设定，但不在序幕中明示：

> **主角不是一台普通的留声机。他是那个碎裂的音乐厅里的留声机。**
>
> 他曾经播放过完整的、美丽的音乐。然后一切碎了，他失去了所有录音，只剩下白噪音。他甚至不记得自己曾经播放过什么——序幕中的和弦是他"遗忘的记忆"的最后一道残响。

这条暗线在中段（⑥ 倒置之塔的旧录音室支线）逐步揭示，终局完全展开。详见 [HiddenThreads.md](./HiddenThreads.md)。
